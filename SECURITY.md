# Security policy

This is an unaudited engineering portfolio project. The supported application mode is local Anvil chain 31337 using valueless demo tokens. Do not use the demo lender/tokens/markets in production. The backend refuses any other chain ID and has no production private-key signer.

Report issues using a private GitHub security advisory when enabled; otherwise contact the maintainer privately through their GitHub profile. Do not post credentials or exploitable details in public issues. See [threat model](docs/SECURITY.md) for assumptions and operational limits.
